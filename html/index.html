Bluetooth

The ESP32-C3 has one radio, so the device does WiFi or Bluetooth, never both. Bluetooth here is BLE with the Nordic UART Service — this chip has no Bluetooth Classic, so apps that pair with a “serial” GPS will not find it.

What happens when you switch

  1. WiFi stops and this page stops responding. That is expected.
  2. The device advertises as gnss-haydamaka and serves the same NMEA sentences over BLE.
  3. The choice is remembered, so it starts on Bluetooth from now on.
  4. Once nothing has been connected over Bluetooth for a couple of minutes, the radio goes back to WiFi and this page returns. A restart does the same.

So Bluetooth cannot leave the device unreachable — it always comes back on its own. To stop it starting on Bluetooth, come back here and press “Start on WiFi instead”.

Using it from a phone

Android apps do not read a GNSS receiver directly. A bridge app reads it and publishes the position as the system mock location provider, after which every other app — Maps, OsmAnd, a survey app — uses this device instead of the phone's own GPS.

Over Bluetooth

  1. Install GPS Connector, which speaks both BLE and TCP. GNSS Master and SW Maps work the same way.
  2. On this page, press Switch to Bluetooth.
  3. In Android, unlock Developer options: Settings → About phone → tap Build number seven times.
  4. Settings → System → Developer options → Select mock location app → choose the bridge app.
  5. In the app pick a Bluetooth LE connection and choose gnss-haydamaka. Do not pair it in Android's Bluetooth settings first — BLE devices are connected from inside the app.
  6. Turn its mock location on. Every other app now follows this device.

Over WiFi

  1. Put the phone on the same network as this device, or join its access point.
  2. In the bridge app pick a TCP/IP connection and give it gnss-haydamaka.local port 10110. Use the address shown above if the name does not resolve.
  3. Set the mock location app as above.

A PC needs no app: gpsd -N -n tcp://gnss-haydamaka.local:10110 feeds the whole desktop, and ble-serial does the same over BLE.
